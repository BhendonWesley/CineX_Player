description: Sincronizar código com o GitHub (Commit, Push e Pull)
---

Este workflow automatiza as tarefas comuns de Git para o repositório CineX-Player.

### 📤 Enviar Alterações (Push)
1. Adicionar todos os arquivos:
```powershell
git add .
```
2. Criar commit com mensagem:
```powershell
git commit -m "Atualizando CineX Player - UI e Funcionalidades"
```
3. Enviar para o GitHub:
```powershell
git push -u origin main
```

### 📥 Receber Alterações (Pull)
1. Puxar novidades do repositório:
```powershell
git pull origin main
```

---
> [!TIP]
> Use este workflow sempre que quiser salvar seu progresso no GitHub ou baixar atualizações de outros dispositivos.
